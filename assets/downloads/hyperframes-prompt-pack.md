# Hyperframes Prompt Pack
## by Jamaal Treasures

Free setup and commands for auto-editing video with Hyperframes inside Claude Code.
Inspired by @colton.ai.dean. Get the tool: github.com/heygen-com/hyperframes

## Setup: paste this into Claude Code

Clone this repo and help me get setup

https://github.com/heygen-com/hyperframes

That is all. Saying "help me get setup" in a fresh repo onboards you with the best experience tailored to you and your niche.

## Editing commands

Talk to the editor like an assistant. Paste these as plain commands:

- Transcribe this video and mark every retake
- Cut all mistakes and dead air, keep the best take of each line
- Captions on every word
- Cut it to 30 seconds
- Zoom in on the logo
- Make the titles bigger
- Add punch-in zooms on key lines
- Speed ramp the b-roll sections

## Export commands

- Export vertical 9:16 for reels
- Export horizontal 16:9 for YouTube
- Burn in captions, large and centered
